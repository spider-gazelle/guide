# Spider-Gazelle Guide

Source for [spider-gazelle.net](https://spider-gazelle.net): guides for the
[Spider-Gazelle](https://github.com/spider-gazelle) ecosystem, plus API reference generated
from the [action-controller](https://github.com/spider-gazelle/action-controller) source.

## Building and serving locally

You need Python 3 and Crystal.

```shell
make serve   # live preview at http://localhost:8000
make build   # build the site into ./site
```

`make` creates a virtual environment in `.venv`, installs `requirements.txt`, and installs
the Crystal shards (the API reference is generated from `lib/action-controller` with
`crystal docs`).

If `python3 -m venv` fails because `ensurepip` is unavailable, create the environment
without pip and bootstrap it:

```shell
python3 -m venv --without-pip .venv
curl -sS https://bootstrap.pypa.io/get-pip.py | .venv/bin/python
.venv/bin/pip install -r requirements.txt
```

CI builds with `mkdocs build --strict`, so check your changes with:

```shell
.venv/bin/mkdocs build --strict
```

## Layout

- `docs/SUMMARY.md`: the navigation.
- `docs/`: the hand-written pages: getting started, guides, OpenAPI, MCP, deployment
  and the AI agent reference.
- API reference pages are generated at build time by `gen_doc_stubs.py` and
  [mkdocstrings-crystal](https://github.com/mkdocstrings/crystal).
- `/llms.txt` and `/llms-full.txt` are generated by
  [mkdocs-llmstxt](https://github.com/pawamoy/mkdocs-llmstxt). Add new pages to its
  `sections` in `mkdocs.yml`.
- Moved pages keep working through `redirects` in `mkdocs.yml`.

## Updating dependencies

Edit `requirements.in`, then regenerate the pinned `requirements.txt`:

```shell
.venv/bin/pip install pip-tools
.venv/bin/pip-compile requirements.in -o requirements.txt
```

To document a new action-controller release, run `shards update action-controller`.
